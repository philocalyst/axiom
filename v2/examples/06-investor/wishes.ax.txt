// ── 1. A stock split changes quantity, not value, basis or date ─────────────
//
// Fastenal split 2-for-1 on 2025-05-22. What was bought 2024-12-10 is still
// bought 2024-12-10, at half the price per share, twice the shares.
//
//   2025-05-22 fidelity split FAST 1:2            // every lot: qty x2, basis and acquired unchanged
//   2025-05-22 FAST 41.90 USD                     // the price series is not adjusted
//
// (a reverse split is `split FAST 10:1`; a spin-off is an exchange with a basis
// allocation: `fidelity spin FAST -> FAST 1 + NEWCO 0.1 basis 90%/10%`)
//
// What Axiom forces today: restate history. The lots are typed already
// split-adjusted, so a statement dated before the split (`fidelity = 100 FAST`)
// no longer reconciles, and the price the trade was executed at is not on file.

// ── 2. A wash sale is a law, and it moves basis ─────────────────────────────
//
//   /// IRC §1091
//   law wash-sale
//     on gain
//     when gain < empty and held <= 1y
//     let repl = bought(unit, from date - 30d to date + 30d, not lot)     // a window over flows, per commodity
//     when repl > empty
//     move min(-gain, ...) into basis of those lots       // a new effect: `adjust basis of PARCELS by X`
//     also    inherit acquired-date of the sold lot        // holding period tacks
//
// Today: the loss is computed by hand, parked in equity/wash-sale, released into a
// second, artificial funding leg of the purchase, and added back to gains by a
// second law. Nothing checks the 30 days.

// ── 3. ESPP: the plan's formula, not two transactions ───────────────────────
//
//   2025-06-30 espp-cash 8_400 USD -> etrade ? NWND
//     price  0.85 * min(price(NWND, 2025-01-02), price(NWND, 2025-06-30))
//     bargain -> wages                             // FMV minus cost, counted as pay, added to basis
//
// Today: `-> etrade 4_150 USD` with two sources (cash and espp-discount), then
// `etrade 4_150 USD -> etrade 25 NWND`, and the discount is worked out by hand.

// ── 4. A network fee is part of the transfer ────────────────────────────────
//
//   2025-04-10 coinbase 6 ETH -> wallet 6 ETH fee 0.0021 ETH
//
// Today: a second flow, `wallet 0.0021 ETH -> network-fees`, which is a disposal
// (a small gain or loss) and an expense, as it should be, but two lines that belong
// together and can be mislinked.

// ── 5. Moving one commodity, choosing lots with quantities ──────────────────
