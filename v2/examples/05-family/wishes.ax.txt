// ── 1. A household is an entity: it owns, it files ──────────────────────────
//
//   entity household : household
//     members alex, jordan            // a tax unit
//     filing  joint
//     lives   us/ca
//
//   account assets/bank/joint-checking : bank
//     owner household                 // or: owner alex, jordan
//
//   account assets/retirement/jordan-401k : 401k
//     owner jordan                    // still per person: limits and ages
//
// The wages of a paycheck belong to whoever the employer is, not to whoever owns
// the account the net pay lands in:
//
//   entity bluefin : employer
//     employs jordan                  // tallies from bluefin's pay are Jordan's
//
// and the return is per tax unit: `tally(agi)` inside a household law sums over
// its members; a per-person limit reads `tally(x, member)`.

// ── 2. Starting balances are not flows ──────────────────────────────────────
//
//   opening 2024-12-31
//     assets/education/riley-529 = 24_600 USD  basis 19_850 USD  since 2019
//     assets/house               = 1 HOME      basis 540_000 USD since 2023-06-15
//     liabilities/mortgage       = 412_428.22 USD
//
// No gift-exclusion warning, no 2024 year-end laws, and the house is held since
// 2023, not since the day the ledger began.

// ── 3. Basis is what you put in, whatever the route ─────────────────────────
//
//   2025-05-16 grandma -> riley-529 3_000 USD contribution
//   2025-06-30 growth  -> riley-529 2_365.31 USD               // earnings, no basis
//
// (today the route decides: from a bank, basis; from an income place, none)

// ── 4. Waivers that waive ───────────────────────────────────────────────────
//
//   2025-11-05 hsa -> joint-checking 620 USD ! "reimburses 2025-05-09 dentist"
//   // drops the 20% penalty AND the taxable-distribution count, or says which one stays

// ── 5. A paycheck is one thing ──────────────────────────────────────────────
//
//   paycheck acme 2025-01-15 5_750 USD
//     pre-tax   alex-401k 575, hsa 250, health-premium 212.50, dcfsa 208.33
//     withheld  federal 692, state 285, fica 388.56, sdi 60.95
//     net       joint-checking
//
// so the forecast lists one recurring paycheck, not nine flows, and a stub can be
// checked (`gross - pre-tax - withheld == net`).

// ── 6. A payment with a statement ───────────────────────────────────────────
//
//   2025-05-01 joint-checking -> lender 3_174.46 USD statement #mortgage-2025-05
//     principal 474.46, interest 2_010.00, escrow 690     // must add up, or an error
//
//   axiom register --txn mortgage      // one line per payment, three columns

// ── 7. Personal-use property has no capital losses ──────────────────────────
//
//   account assets/vehicle/crv : vehicle
//     personal-use                      // gains taxable only above cost; losses never deductible
//
//   account assets/house : property
//     primary-residence                 // §121 exclusion: 500_000 USD joint

// ── 8. Amounts, not totals ──────────────────────────────────────────────────

//   law gift-exclusion

//     when from is not income
//     warn total(in, year, from is not income) <= gift-exclusion[year]
