// Wishes for the freelancer project: how this ledger would be written if the
// language could say it. NOT loaded (the loader reads only *.ax files).
// Every wish is answered in ../FINDINGS.md with a proposed design.

// ── 1. An invoice is a claim with terms, not two flows and a convention ─────
//
// Today: `income/design -> brightwave 3_200 USD #inv-2025-b02` and later
// `brightwave -> business 3_200 USD #inv-2025-b02`, tied together only by a
// code, with no due date, no partial payment and no aging.
//
//   2025-02-03 brightwave owes 3_200 USD due 2025-03-05 #inv-2025-b02 / design
//   2025-03-14 brightwave pays #inv-2025-b02                  // the rest, into business-checking
//   2025-04-20 orbit-labs pays 2_750 USD #inv-2025-o1         // partial
//   2025-12-15 delta-rugs writes off #inv-2025-d1             // the claim ends; no cash
//
//   axiom claims --at 2026-02-10     // open invoices, days late, oldest first

// ── 2. Payments have a tax year of their own ────────────────────────────────
//
// The fourth estimate is paid 2026-01-14 and belongs to 2025.
//
//   2026-01-14 tax-vault -> federal 2_400 USD / irs for 2025 #q4-2025
//   2026-01-28 business-checking -> sep 2_000 USD for 2025

// ── 3. Pre-tax money is a property of the flow, not of where it came from ───
//
//   2025-06-27 business-checking -> sep 2_000 USD @ basis empty     // deducted contribution
//   2025-06-27 business-checking -> sep 2_000 USD deducted          // shorter

// ── 4. A statement value is a valuation, not a flow ─────────────────────────
//
//   2025-03-31 sep ~ 17_964.65 USD      // the custodian says it is worth this; no flow, no distribution

// ── 5. Deductible share belongs on the account ──────────────────────────────
//
//   account expenses/home
//     deductible 15%                    // instead of a law that multiplies by a param
//   account expenses/phone
//     deductible 60%

// ── 6. Accounting method is a property of the person ────────────────────────
//
//   entity me : person
//     method cash                       // receipts count when received; write-offs never deduct

// ── 7. A payment schedule that respects the calendar ────────────────────────
//
//   every quarter on 04-15 06-15 09-15 01-15  next-business-day
//     tax-vault -> federal 3_000 USD / irs for prior 0

// ── 8. Laws that say what they need ─────────────────────────────────────────
//
//   law self-employment-year
//     each year
//     after count-wages, credit-withholding       // an explicit order instead of file order
//     before federal-income-tax
//
//   us exposes hooks:  count x as deduction | credit | above-the-line

// ── 9. Cumulative-at-date reads ─────────────────────────────────────────────
//
//   law estimate-2
//     by 2025-06-16
//     warn paid(federal, for 2025, through 2025-06-16) >= 50% * prior-year-tax
//     // a `paid` function that knows the tax year and the day, not the calendar year of today

// ── 10. Fees netted from a deposit ──────────────────────────────────────────
//
//   2025-03-28 fernhill pays 4_500 USD less 130.80 USD fees -> business-checking
//   // = one flow from receivable, 4_369.20 to the bank and 130.80 to fees, no legs to balance
