# Native model test migration checklist

This inventory records the 73 tests present in the pre-cutover `model/src/tests.rs` at the `e7d533a` native-record checkpoint. The old suite used the removed v3 collection/flow API. This checklist prevents the source-file replacement from being mistaken for migration closure. Check a row only after its native equivalent passes; tests owned by Parser, Engine, Context or Forecast need their evidence in those crates or an integrated source fixture.

Current model-source coverage is still incomplete: fifteen source-driven declaration tests in `model/src/tests.rs` and three cross-namespace/resolution tests in `model/src/names_tests.rs`; focused tests also live in `names.rs`, `props.rs`, `params.rs`, `laws/`, `sync_lower.rs`, `journal.rs`, and `lower.rs`. The current checkpoint passes 56 model unit tests, ten native-record integration tests, and six native-law integration tests using the replacement test module. This passing suite does not close the behaviors still marked Pending or Partial below; parser, engine, context, and forecast owned evidence must be linked as those ports land.
